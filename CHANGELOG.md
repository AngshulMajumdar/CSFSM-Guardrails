# Changelog

## 0.1.0 — 2026-11-22

Initial implementation of CSFSM conversational guardrails: finite-mode Bayesian
filtering, joint kernels, protocol constraints, robust risk masking, KL
projection, deterministic or sampled action selection, enforcing generation and
tool wrappers, Memory/SQLite state, authenticated FastAPI endpoints, sync/async
HTTP clients, LangChain/LangGraph adapters and a standalone CPU Gradio Space.
